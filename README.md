# MTP_lab_1
# Работа с разряженными матрицами на С++

Краткое описание: Работа с разряженными матрицами на С++. Полная их обработка

## Требования

- Установленный [Git](https://git-scm.com/downloads)
- Аккаунт на GitHub

## Первоначальная настройка(один раз)

### 1. Клонировать репозиторий

```bash
git clone https://github.com/[username]/[repo].git
cd [repo]
```
### 2. Зарегистрироваться
```bash
git config --global user.name "Ваше Имя"
git config --global user.email "ваш@email.com"
```


## Каждый раз перед началом работы
### 1. Загрузить текущую основную версию программы (main)
```bash
git checkout main
git pull origin main
```
### 2. Создать ветку под задачу
```bash
git checkout -b feature/имя-задачи
```
### 3. После написания кода.

Посмотрите че изменили(не обязательно)
```bash
git status
git diff
```
Добавьте нужные файлы
```
git add имя-файла      # один файл
git add .              # все файлы
```
Подтвердите что все изменения внесены
```bash
git commit -m "Краткое описание, что сделано"
```

Примеры сообщений:

    Добавил функцию по загрузке матрицы из файла
	
    Исправил баг при вводе нулевой матрицы

### Загрузите ветку на гитхаб
```bash
git push -u origin feature/имя-задачи
```

### Открываете PR(Pull request) если доделали
1) Зайти на GitHub

2) Нажать request.

3) Выбрать:

    base: main
	
    compare: написанная ветка

4) Заполнить:

    Заголовок — что сделано.

    Описание — как проверить, на что обратить внимание и доп информация

5) Нажать Create pull request.

6) Написать в ВК что функция сделана.
